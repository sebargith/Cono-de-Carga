# Entregables

- `informe_final/`: informe de Cono de Carga, figuras y fuentes visuales.
- `metodologia/`: documento autónomo con la metodología general del sistema.
- `presentacion_psinet/`: presentación y resultados compactos de la muestra de
  1.248 imágenes.
- `evaluacion_tecnica_90/`: métricas, resumen y comparaciones de la evaluación
  de rendimiento del analítico sobre 90 imágenes.

Las comparaciones individuales se mantienen localmente y no se versionan para
evitar aumentar innecesariamente el tamaño del repositorio.

Los documentos usados como referencia para redactar el informe permanecen en
`informe_final/referencias/`, también excluidos de Git. El DOCX final, las
figuras y sus fuentes seleccionadas sí forman parte del entregable versionado.
