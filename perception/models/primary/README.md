# Modelo principal

`psinet_carga_visible.pt` es el modelo de segmentación usado por defecto por el
pipeline integrado.

La clase que representa la carga visible es `material` (`class_id=1`). Este
valor está configurado en `configs/perception_config.yaml`.

Ruta dentro de Docker:

```text
/workspace/models/primary/psinet_carga_visible.pt
```
